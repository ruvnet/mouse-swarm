Prepare the requested MP4 export: $ARGUMENTS. Follow `${CLAUDE_PLUGIN_ROOT}/docs/activity-and-video.md` and `${CLAUDE_PLUGIN_ROOT}/docs/playwright.md`. Use the user's trusted local HTML or a saved activity recording, verify Playwright, an installed browser and FFmpeg, and verify the output format and dimensions. Default to portrait 9:11 only if the user has not specified a format. Recordings may contain agent identifiers; do not publish them without authorization. Explain that activity video rescales observation timestamps and simulated cursors are not native telemetry.
