# Deploy a public reveal on Cloudflare

The reveal is a browser animation. Deploy your own authorized page as static assets on Cloudflare Workers; it does not need a Ruflo server. Keep private Ruflo observation on your local machine unless you have designed authentication, authorization, and data minimization for remote access.

## Prepare the site

1. Build your app so its output directory contains an `index.html` and the browser module. For a bundler, follow your app's build command. For the no-build example, follow the README quick start and use that example directory as your asset directory.
2. Install Wrangler in your own project and authenticate using Cloudflare's [Workers static assets instructions](https://developers.cloudflare.com/workers/static-assets/).
3. Create a `wrangler.jsonc`, replacing the name and directory with your own:

```jsonc
{
  "name": "my-swarm-reveal",
  "compatibility_date": "2026-11-07",
  "assets": { "directory": "./dist" }
}
```

4. Preview with `npx wrangler dev`, then deploy with `npx wrangler deploy`. Open the printed URL and verify playback, controls, mobile layout, and reduced motion.

The repository's existing `site/worker.mjs` is a separate prebuilt demo; its embedded content is not automatically regenerated by editing `examples/`. Custom domains require access to the DNS zone and the appropriate Cloudflare account. Never embed API tokens or private swarm records in static assets.
